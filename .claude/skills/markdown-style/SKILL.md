# Markdown 编写规范(markdownlint)

编写或修改任何 `.md` 文件时,必须符合仓库根目录 `.markdownlint.json` 的规则。
该配置文件是唯一事实源;下面是需要重点遵守的具体条目:

- **MD040 代码块必须标注语言**:所有 ` ``` ` 开栏都要带语言标识。
  纯文本/目录树/清单用 ` ```text `,配置文件用 ` ```yaml ` / ` ```json` / ` ```cmake ` 等。
- **MD060 表格列样式统一(compact)**:表格所有行——含表头、分隔行、数据行——
  竖线两侧各留 **1 个空格**。分隔行写成 `| --- | --- |`,不要写成 `|---|---|`。
- **MD022 / MD032 / MD031 / MD058 空行**:标题、列表、代码块、表格的**前后都要空一行**。
- **MD013 行宽**:本仓库已在 `.markdownlint.json` 关闭(中文文档不限行宽),无需强行折行。
- **MD001 标题递增**:标题层级逐级递增(`#` → `##` → `###`),不可跳级。
- **MD012**:不允许连续多个空行(最多 1 行)。
- **MD009**:行尾不留多余空格。

写完 `.md` 后,若环境可用,运行 `markdownlint-cli2 "<文件路径>"` 自查并修正后再交付。
